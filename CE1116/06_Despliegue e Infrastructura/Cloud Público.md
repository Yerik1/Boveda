## 📚 Idea/Concepto 

El Cloud Público es un modelo de computación en la nube donde un proveedor externo ofrece recursos como servidores, almacenamiento, redes, bases de datos o aplicaciones a través de internet. Estos recursos operan bajo un modelo de multitenancy, donde varios clientes comparten la infraestructura física, pero permanecen aislados lógicamente mediante virtualización y controles de software. Se caracteriza por el autoservicio, la elasticidad, el aprovisionamiento rápido, el pago por uso y un modelo de responsabilidad compartida entre proveedor y cliente
