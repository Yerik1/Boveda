## 📚 Idea/Concepto 

La Definition of Done (DoD) es el acuerdo de calidad mínima para decir “esto está realmente terminado”. Evita que algo se marque como “done” si no cumple pruebas, revisión o criterios necesarios para considerarlo entregable.
