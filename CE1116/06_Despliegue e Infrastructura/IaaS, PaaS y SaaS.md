## 📚 Idea/Concepto 

IaaS, PaaS y SaaS son modelos de servicio cloud que se diferencian por el nivel de control y responsabilidad del usuario. En IaaS, el proveedor ofrece infraestructura virtualizada como servidores, redes y almacenamiento, mientras el usuario gestiona el sistema operativo, datos y aplicaciones. En PaaS, el proveedor administra la infraestructura, el sistema operativo, el runtime y el middleware, mientras el usuario se enfoca en el código, los datos y la configuración de su aplicación. En SaaS, el proveedor entrega una aplicación completa lista para usar y administra la mayor parte de la plataforma, mientras el usuario solo configura y consume el servicio.
