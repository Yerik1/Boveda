## 📚 Idea/Concepto 

Una Virtual Private Cloud (VPC), es un entorno de red lógico y aislado dentro de una nube pública. Funciona mediante principios de Redes Definidas por Software, SDN, lo que permite configurar subredes, rangos de IP, reglas de firewall, tablas de enrutamiento y conexiones mediante interfaces, APIs o CLI. Aunque utiliza infraestructura compartida del proveedor, permite al usuario controlar su red de forma segura, flexible y programática.
