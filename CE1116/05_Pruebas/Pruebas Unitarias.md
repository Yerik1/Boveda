## 📚 Idea/Concepto 

Las pruebas unitarias validan partes pequeñas del código (funciones, métodos, módulos) de forma aislada, asegurando que cada unidad haga lo que debe. Ayudan a detectar errores temprano y a refactorizar de una manera sencilla.
