## 📚 Idea/Concepto 
El Cloud Híbrido es un modelo que integra infraestructura local, nube privada y/o nube pública para que trabajen de forma coordinada. No consiste solo en tener varios entornos separados, sino en conectarlos mediante redes, seguridad, gestión y orquestación. Normalmente se apoya en plataformas o estándares comunes para facilitar la portabilidad de aplicaciones y datos. Se usa cuando se requiere flexibilidad, cumplimiento normativo, soberanía de datos, baja latencia o control sobre ciertas cargas de trabajo, aunque implica mayor complejidad operativa.
